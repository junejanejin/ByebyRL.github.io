流程基础

概率与更新

关键词 定义 详见
logp / log_prob 模型给某 token 的对数概率 一 1.1
old_log_prob 更新前的基准概率（采样后、更新前由训练引擎前向算出） 一 1.1
ratio exp(logp − old_log_prob)，当前策略偏离采样策略的幅度 一 1.1
logpdiff logp − old_log_prob = log(ratio)，指标表名 一 2
clip / 裁剪 把 ratio 限制在 1±ε 内，防单步更新过猛 一 1.1
advantage（A） reward 经组内比较变形：比同组好为正、差为负，决定更新方向 一 1.1
baseline advantage 的参照（组均值或 critic 估值） 三 2
GAE PPO 里用 critic 估计 advantage 的方法 三
KL 散度 两个分布的差异度量；约束 actor 不偏离 ref 三 2
entropy（熵） 输出多样性；持续下降=熵塌缩 一 2
policy_loss / pg_loss 策略损失，训练的直接优化目标 一 1.1
反向传播 按 loss 计算每个参数调整量的过程 一 1.1
梯度 / grad_norm 参数调整的方向与幅度；grad_norm 突增=更新异常 一 2
优化器 / optimizer.step 按梯度×学习率真正改权重的环节 一 1.1
ppo_epochs 同一批数据重复更新的遍数 一 1.1

模型角色

关键词 定义 详见
actor 策略模型，唯一被更新的对象 三 2
ref / reference 冻结的初始模型，算 KL 防跑偏；DAPO 去 KL 时可不配 三 2
critic / value 网络 价值模型（同一概念）：输入状态、输出预期总奖励 V(s)；PPO 用它算优势，GRPO 不用 三 2
reward model（RM） 学习"哪个回答更好"的打分模型；可验证任务用规则替代 一 1.1
policy（策略） 模型当前的生成行为分布 一

算法

关键词 定义 详见
PPO clip ratio 限制更新步长 + critic/GAE 的经典算法 三
GRPO 去 critic 的 PPO：组内均值当 baseline 三
DAPO GRPO 四改良：clip-higher、动态采样、token 级 loss、去 KL 三
GSPO 裁剪从 token 级提到序列级；大规模/MoE 更稳 三
DPO 不用 RL、直接从偏好对训练的对齐方法 三
dynamic sampling 过滤全对/全错组，凑不满继续推理 三
clip-higher 非对称裁剪，上界放宽，防熵塌缩 三
reward hacking 模型钻评分空子刷分（如靠冗长） 一 2
熵塌缩 回答趋同、多样性丧失，学习停滞 一 2
RLVR 可验证奖励（数学/代码对答案），替代 RM 一 1.1

并行与显存

关键词 定义 详见
DP 数据并行：各卡不同数据；FSDP 是参数分片版 四
TP 张量并行：切每层权重矩阵的行/列 四
PP 流水线并行：按层切段，各卡一段 四
EP 专家并行：MoE 专家分布到不同卡 四
SP / CP 序列并行/上下文并行：长序列切给多卡算 attention 一 3
FSDP PyTorch 原生训练引擎（DP 参数分片） 四
Megatron-LM / mcore NVIDIA 大规模训练库；mcore 是其权重格式（HF↔mcore 需转换） 四
all-gather 从各卡分片收齐完整张量 一 1
重计算 / activation checkpointing 不存中间激活、用时重算，省显存换时间 一 3 / 六
offload 参数/优化器状态用完卸回内存 一 3
KV Cache 推理时缓存的 K/V，随并发×序列长线性涨 六
PagedAttention vLLM 的分页 KV 管理 四
RadixAttention SGLang 的前缀 KV 树缓存，多轮命中率高 四
continuous batching 请求动态进出批，推理吞吐关键 四
preemption / 抢占 KV 池不够时暂停/重算请求，吞吐骤降的信号 六
